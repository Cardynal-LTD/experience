# Quickstart

Get up and running with Cardynal in 5 steps. By the end, you'll have an AI agent answering customer questions on your website.

## Step 1: Create Your Account

1. Go to the Cardynal signup page
2. Enter your email, password, name, and company name
3. Your workspace is created automatically with a 14-day trial

After signing in, you'll land on the **Dashboard**. An onboarding checklist guides you through the initial setup:
- Create an Agent
- Connect an Inbox
- Add a Source

## Step 2: Create an AI Agent

1. Go to **Agents** in the sidebar
2. Click **+ New Agent**
3. Enter a name (e.g., "Support Bot") and click **Create**
4. On the agent config page, set:
   - **System prompt** — Instructions for how the agent should behave
   - **Tone** — Professional, Friendly, or Casual
   - **Response length** — Short, Medium, or Long

Your agent is now ready. You can refine it later by adding playbooks, tools, and escalation rules.

## Step 3: Connect a Channel

1. Go to **Integrations** in the sidebar
2. Click **+ Add Integration**
3. Select **Web Chat** to start with the simplest channel
4. Name your inbox (e.g., "Website Chat")
5. Assign the AI agent you just created
6. Copy the embed code and add it to your website

For other channels (WhatsApp, Gmail, etc.), see [Connecting Channels](./connect-channels.md).

## Step 4: Add Knowledge Sources

Your AI agent needs knowledge to answer questions accurately.

1. Go to **Sources** in the sidebar
2. Click **+ Add Source**
3. Choose a source type:
   - **Website/Sitemap** — Enter a URL; Cardynal crawls and indexes the pages
   - **Documents** — Upload PDF, DOCX, TXT, MD, or CSV files
   - **Manual** — Write or paste content directly
4. Wait for processing to complete (status changes from "Processing" to "Complete")
5. Assign the source folder to your agent via **Agents → [Your Agent] → Knowledge Base**

See [Training Your AI](./train-your-ai.md) for optimization tips.

## Step 5: Invite Your Team

1. Go to **Team** in the sidebar
2. Click **+ Add Member**
3. Enter their email, name, and role:
   - **Admin** — Full access to settings, agents, workflows
   - **Agent** — Access to inbox, tickets, and contacts
4. They'll receive temporary credentials to sign in
