# Welcome to Cardynal

Cardynal is a B2B2C AI customer support platform that empowers SaaS companies to deliver exceptional support experiences across every channel.

## What is Cardynal?

Cardynal provides a unified platform for managing customer conversations across multiple channels. AI agents handle routine inquiries automatically, while your team focuses on high-value interactions that require human judgment.

## Key Features

**Unified Inbox**
Manage conversations from all channels — web chat, WhatsApp, email, Instagram, Messenger — in a single inbox. Assign, prioritize, and collaborate with your team in real time.

**AI Agents**
Deploy intelligent agents powered by OpenAI or Anthropic models. Configure their personality, assign playbooks for structured conversation flows, connect API tools, and set escalation rules for seamless human handoff.

**Knowledge Base**
Upload documents, crawl websites and sitemaps, or add content manually. Your AI learns from this knowledge using vector embeddings to provide accurate, contextual responses.

**Ticketing System**
Track issues with custom ticket types, SLA deadlines, priorities, and custom fields. Link tickets to conversations, manage them in list or kanban view, and keep a full audit trail with comments.

**Workflow Automation**
Build visual workflows with a drag-and-drop DAG editor. Trigger on events, schedules (cron), webhooks, or manually. Use 20+ node types including conditions, loops, HTTP requests, code execution, and more.

**Analytics Dashboard**
Track sessions, AI resolution rate, response times, ticket status, and team performance. Monitor playbook usage and escalation patterns.

**Channels & Integrations**
Connect web chat, WhatsApp (via Meta Business API or Unipile), Gmail, Instagram, and Messenger. Install third-party integrations from the catalog.

**Team Management**
Invite team members with owner, admin, or agent roles. Set availability schedules, track presence, and manage assignments.
